# 聊天文字调色（SillyTavern 扩展）

给酒馆聊天消息改色的 UI 扩展：主要文本、斜体文本、引用文本三类文字可**分别**调色，支持「跟随主题 / 纯色 / 渐变」，渐变可自定义 2~4 个颜色与角度、带霓虹光晕开关与强度，并内置 10 套配色预设与 3 套可保存的自定义预设。面板跟随酒馆主题与字体大小。

## 安装

1. 把本文件夹整体复制到酒馆的用户扩展目录：

   ```
   SillyTavern/data/<你的用户名>/extensions/聊天文字调色/
   ```

   最终结构为：`extensions/聊天文字调色/manifest.json`、`index.js`。

2. 重启酒馆（或刷新页面）。
3. 进入 **扩展（Extensions）→ 管理扩展**，确认「聊天文字调色」已启用。
4. 打开 **扩展设置**，找到「聊天文字调色」面板开始配置。

## 功能对照

| 需求 | 实现 |
| --- | --- |
| 只改聊天消息 | 染色仅作用于 `#chat` 内的消息，不碰角色卡、设置等其他界面；代码块（行内 `code`、`pre`）保持原样 |
| 插件总开关 | 面板顶部「启用聊天文字调色」开关，一键停用/恢复；停用后聊天保持酒馆原生样式 |
| 三类文字横排切换 | 面板顶部横排「主要文本 / 斜体文本 / 引用文本」标签，逐类设置 |
| 跟随酒馆主题 | 每个类别都提供「跟随主题」模式，不做任何处理；面板配色、字体大小跟随酒馆 |
| 纯色 | 可选任意颜色（色块 + Hex 输入 + 取色器） |
| 渐变 | 自定义 2~4 个颜色（可添加/移除），角度 0~360° 可调 |
| 光晕 | 渐变模式下有「霓虹光晕」开关与强度（0~100%）；逐字三层 `text-shadow` 辉光，每个字散发自己颜色的光晕（蓝段蓝光、白段白光、黄段黄光） |
| 流式实时渐变 | 流式生成期间先以渐变中点色 + 同色光晕近似呈现，生成结束后自动逐字精确校正；每字颜色与光晕都跟随该字在渐变中的位置 |
| 渐变粒度 | 主要文本 = 整条消息；**斜体 = 每个 `em` 段落**；**引用 = 每个 `q` / `blockquote` 整段**（连续渐变，中间色自然铺开、方向统一） |
| 内置预设 | 10 套配色预设位于配色设置下方；点击套用：斜体与引用应用渐变并开启光晕（强度 100%），主要文本改为跟随主题 |
| 自定义预设 | 3 套可保存槽位，调好配色点「存入」，点「使用」一键切换 |
| 取色器 | 参考常见拾色器：色板（饱和度/明度）+ 色相条；右侧依次为色值预览、Hex、RGB 与确定按钮，实时联动 |

## 使用说明

- **切换类别**：点击顶部标签（主要文本 / 斜体文本 / 引用文本），下方显示该类别的配置。
- **配色模式**：跟随主题 / 纯色 / 渐变，切换后显示对应选项。
- **渐变颜色**：每行「色块 + Hex 输入 + 调色板按钮」，点击调色板按钮展开取色器；最多 4 色、最少 2 色，可点「＋添加颜色」在末尾前插入中间色，「－」移除。
- **光晕**：勾选「霓虹光晕」后出现强度滑块；每个字单独散发「该字颜色」的三层 `text-shadow` 光晕（贴字亮边 + 中层 + 外晕），强度同时控制光晕半径与透明度，100% 即原始霓虹参数。
- **内置预设**：点击色卡即套用（斜体与引用应用渐变并开启光晕 100%，主要文本改为跟随主题），套用后可再逐类微调。
- **自定义预设**：调好某一类别的渐变配色后点「存入」保存到槽位；点「使用」把配色套用到斜体与引用，主要文本改为跟随主题。
- **总开关**：面板顶部勾选「启用聊天文字调色」生效；取消勾选即停用（聊天保持原生样式），再次勾选恢复配色。
- **实时生效**：修改后即时重染可见与后续消息；流式生成期间以中点色 + 同色光晕近似呈现，生成结束后自动逐字校正，观感一致。
- 「重新渲染可见消息」手动清理残留染色并重载配色样式；「全部恢复跟随主题」一键还原（自定义预设槽位保留）。

## 设计说明

- **光晕观感**：每个字单独上色并单独发光——文字先按渐变方向逐字取色，再给每个字加同色三层 `text-shadow`（贴字 `2px/1.0`、中层 `8px/0.85`、外晕 `24px/0.50`），蓝段蓝光、白段白光、黄段黄光；以最高优先级（!important）写入，避免被主题样式覆盖。
- **性能**：
  - 逐字染色按需触发（设置变化 / 生成结束 / 消息进入视口），流式期间走中点色近似兜底与稳定窗口门控，避免高频重建；
  - 每字颜色按其在渐变方向上的真实位置投影取色，方向与中间色分布随角度自然铺开；
  - 光晕为逐字 `text-shadow`，不创建 filter 合成层，长文本性能更稳。

## 注意事项

- 若同时启用了带光晕/渐变的 UI 主题：主题对 `q`/`blockquote` 自带的光晕与渐变会与插件效果叠加，建议二选一，或在插件中关闭对应光晕。
- 斜体与引用嵌套时，以斜体的设置优先（斜体文字按斜体规则染色）。
- 若「主要文本」设为渐变、而斜体/引用为「跟随主题」：主要文本整条渐变会作用于整条消息，斜体/引用文字也会呈现主要文本的渐变；如需各司其职，请为斜体/引用分别选择纯色或渐变（推荐直接使用内置预设，主要文本会自动设为跟随主题）。
- 流式输出期间：新文字先以渐变中点色 + 同色光晕近似呈现，生成结束后自动逐字校正为精确渐变与每字光晕，属正常行为。
- 建议配合酒馆设置：开启 **No Blur**、关闭「流式淡入」动画，观感更稳定。

## 版本

v1.1.14
- 光晕改为「每字同色」：运行时切回逐字染色引擎，每个字按渐变方向单独取色，并散发该字自己的三层 `text-shadow` 光晕（贴字 2px/1.0、中层 8px/0.85、外晕 24px/0.50），不再使用元素级「内层首色、外层尾色」的一刀切 drop-shadow。
- 流式兜底同步改为「渐变中点色 + 同色光晕」近似，生成结束后自动逐字精确校正。
- 光晕强度缩放改为线性（100% 即原始霓虹参数）。
